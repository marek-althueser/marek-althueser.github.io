## Projekte

**Digitaler Notfallpass** (Mitwirkender)
System, mit dem man im Notfall schnell an lebenswichtige Daten einer Person kommt. Ersthelfer sehen nur das Wichtigste, Ärzte und Rettungskräfte alle freigegebenen Angaben. Anmeldung per Personalausweis über die AusweisApp, Daten in Frankfurt, auf DSGVO-Konformität ausgelegt.

**Lernapp** (eigenes Projekt, privat)
Statt für eine Lernapp zu bezahlen, die nicht zu meinem Lernen passt, entwickle ich meine eigene: Aus den Themen einer Prüfung entsteht ein Lernplan, Funktionsgraphen und Abläufe aus Experimenten werden interaktiv erklärt. Lokales KI-Modell als Tutor, lokale Speicherung.

**GoTrend** (eigenes Projekt, privat)
Lokale App mit lokaler KI, die Marktnachrichten und Analysen zeigt und Einschätzungen gibt (Kaufen, Verkaufen, Abwarten). Live-Daten von Yahoo Finance. Bleibt wegen der Finanzregeln privat, keine Anlageberatung.

**Animanymals** (für einen Freund gebaut)
Website für einen Halter exotischer Kleintiere, gebaut mit Next.js, TypeScript und Tailwind CSS v4. Kein Webshop: Jedes Angebot zeigt eine Preisklasse und öffnet eine vorformulierte E-Mail. Live: [animanymals.com](https://animanymals.com)

Screenshots zu allen Projekten gibt es auf der Portfolio-Seite. Der Quellcode ist privat, Vorführung und Lesezugriff gebe ich auf Anfrage.

## Über dieses Repository

Die Seite besteht aus einer einzigen Datei, `index.html`, ohne Framework und ohne Build-Schritt. Alle Screenshots sind direkt als Base64 eingebettet, deshalb gibt es keinen Bilder-Ordner.

**Lokal ansehen:** `index.html` im Browser öffnen.

**Veröffentlichen:** Die Datei lässt sich auf jedem statischen Hoster bereitstellen, zum Beispiel GitHub Pages, Vercel oder Netlify.
